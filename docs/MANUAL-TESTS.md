# 实机回归清单

适用于 Smart Input 0.2.0 及后续版本。0.2.0 已完成自动化测试、VSIX 包结构校验、搜狗拼音适配和当前支持范围内的实机验证；本清单用于后续版本回归。

## 安装之前

1. 保存正在编辑的文件。
2. 建议使用 VS 的实验实例或其他独立实例，不直接影响日常开发环境。
3. 当前 VSIX 未签名。安装器出现未知发布者提示时，请先核对 VSIX 来源和 SHA256。
4. 实验实例会产生独立的 VS 配置和缓存；扩展运行期间会改变该实例的输入态和临时光标样式。
5. 不改变系统默认输入法、微软拼音兼容模式或快捷键设置。
6. 出现问题时先点击编辑器底部的 `Smart Input` 暂停；状态栏隐藏或按钮不可用时使用 `工具 > Smart Input: 暂停自动切换`。如果菜单也不可用，请关闭独立实例，并仅在该实例中禁用扩展。

## 场景

- 安装 0.2.0 后重启 VS：扩展管理器显示版本为 0.2.0。
- `工具 > 选项 > Smart Input > 常规`：只显示长期设置，不显示临时暂停项。
- 修改手动覆盖光标颜色：进入手动覆盖后光标使用新颜色；退出覆盖后恢复原生光标。
- 修改状态栏文字颜色：启用自定义颜色后底部 `Smart Input` 状态按钮文字变化；关闭后跟随 VS 主题。
- 关闭“显示左下角状态栏”：状态按钮消失；`工具 > Smart Input: 暂停自动切换/恢复自动切换` 仍可操作临时暂停。
- 关闭“启用自动切换”：不读写输入法、不显示手动覆盖光标；工具菜单命令不能绕过总开关。
- 重新启动 VS：长期设置应保留；临时暂停状态不应保留。
- 第一次进入普通代码：英文；进入已有注释：中文。
- 输入 `//`、`/*` 后开始中文；`*/` 后回到代码恢复英文。
- 注释内换行（包含自动补 `*`、`///`）及单行注释结束后换行。
- `int count = 0; // 当前数量`：左右两部分分别英文/中文。
- `printf("加载成功");`：字符串内中文，引号外英文。
- 空字符串、URL、反斜线转义、C++ raw string、C# verbatim/raw/interpolated string。
- C# `$"数量：{count}"`：文字中文，表达式英文；嵌套字符串、注释分别判断。
- 注释中使用输入法实际配置的切换键切到英文并输入 TODO：显示配置的覆盖光标颜色，连续输入不抢回。Shift 仅在输入法设置中已启用时适用，也可使用 Ctrl＋空格等实际配置。
- 代码中手动切中文：显示覆盖光标颜色；再切英文恢复原色。
- Shift+字母、Shift+方向键、Ctrl+Shift 快捷键：不能仅因按 Shift 误判切换。
- 自动切换前后立即使用已配置的切换键：手动选择应保留，不应闪烁或反复抢切。
- 拼音尚未上屏、候选窗打开时：不切换；数字选词、空格上屏、Escape 取消后恢复判断。
- 鼠标移动、方向键、Home/End、点击中文段、切换文档、拆分窗口。
- 有选区、矩形选区、多光标：暂停自动判断，恢复单光标后按场景切换。
- 点击底部按钮：所有文档暂停/恢复；暂停时还原光标；再次点击恢复。
- 点击 `工具 > Smart Input: 暂停自动切换/恢复自动切换`：效果与底部按钮一致，菜单文字随状态变化。
- 焦点进入补全框、重命名框、搜索框、终端或其他软件：不得主动切换；同时观察 Windows 自身是否继承输入态。
- 主题切换、覆盖光标、失焦、关闭文档：恢复新主题的正常光标颜色，不遗留自定义装饰。
- 输入法切换失败：显示未确认，不持续重试；换区域后可以重试。
- 切换到其他输入法：不主动切回微软拼音，不尝试控制不支持的输入法。
- 搜狗拼音：进入代码、注释、字符串和失焦场景时，英文/中文状态、手动覆盖、候选窗、Escape、切换文档和切回微软拼音。
- 搜狗拼音与微软拼音共存：只控制当前活动 Profile，不主动激活或切换另一个 Profile。
- `#if` 非活动代码、复杂宏、C++ 行拼接、C# 插值格式段：记录识别偏差。
- 大文档和快速输入：不阻塞 UI；旧分析结果不能作用于新快照。
