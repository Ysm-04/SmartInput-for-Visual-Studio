# 隐私与本地处理说明

Smart Input 是本地 Visual Studio / SQL Server Management Studio 扩展。本项目不包含联网代码，不上传源码、按键、候选词或输入法内容。Visual Studio 与 SSMS（18/19/20/22）使用同一套本地逻辑，隐私边界完全相同。

## 本地读取

扩展在受支持的 C/C++、C#、XAML 和 Transact-SQL 编辑器 / 查询视图中读取当前文档快照，用于判断光标位置属于代码、注释、字符串、字符字面量、XAML 标记 / 属性值还是 T-SQL 标识符。XAML 设计器预览界面与调试器表达式窗口（监视 / 即时 / 快速监视）不在接管范围内。分析发生在本机宿主进程内，结果只用于当前编辑器会话。

扩展会读取当前活动输入法状态，用于判断微软拼音或搜狗拼音当前是中文还是英文，并在需要时请求切换对应输入法的内部中英文状态。

## 本地写入

扩展不会修改源文件内容，不自动替换标点，不写入候选词，不记录键盘输入。

扩展会写入宿主（Visual Studio / SSMS）用户设置中的长期配置，包括：

- 是否启用自动切换。
- 是否显示左下角状态栏。
- 手动覆盖光标颜色。
- 是否自定义状态栏文字颜色。
- 状态栏文字颜色。
- 是否自定义状态栏背景色。
- 状态栏背景色。

临时暂停状态只保存在当前宿主进程内，不写入用户设置。

## 安装与部署脚本

扩展运行时本身不会写入源码或联网。SSMS 安装、卸载脚本属于用户主动执行的本地管理工具，会在 `-WhatIf` 以外的正式操作中：

- 向 SSMS 的 `Common7\IDE\Extensions\SmartInput` 目录写入或删除扩展文件。
- 在删除既有 `privateregistry.bin` 前，将其备份到 `SmartInput-PrivateRegistry-Backup`。
- 清理 SSMS 私有注册表缓存与 `ComponentModelCache`，并写入 `extensions.configurationchanged` 标记，使宿主重新发现扩展。
- 对部署文件执行 `Unblock-File`，移除浏览器下载文件可能携带的网络区域标记。

这些脚本不上传上述文件或缓存。正式部署和卸载前应关闭 SSMS，并先使用 `-WhatIf` 核对目标路径和计划执行的操作。

## 不做的事

- 不联网。
- 不采集遥测。
- 不读取或上传完整键盘记录。
- 不读取或上传输入法候选词。
- 不主动安装、添加或切换系统键盘布局。
- 不修改系统默认输入法、微软拼音快捷键或兼容模式。
- 不写入宿主的字体和颜色主题配置。

## 诊断与反馈

构建和验证脚本默认在运行者本机执行，不包含数据上传逻辑。反馈问题时，建议使用 `samples` 目录中的无敏感示例复现，并记录系统版本、Visual Studio / SSMS 版本、扩展版本、输入法版本、操作步骤和实际表现。不需要提交私人源码、候选词或完整按键记录。
