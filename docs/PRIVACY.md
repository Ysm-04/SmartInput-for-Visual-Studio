# 隐私与本地处理说明

Smart Input 是本地 Visual Studio 扩展。本项目不包含联网代码，不上传源码、按键、候选词或输入法内容。

## 本地读取

扩展在受支持的 C/C++ 和 C# 编辑器视图中读取当前文档快照，用于判断光标位置属于代码、注释、字符串还是字符字面量。分析发生在本机进程内，结果只用于当前编辑器会话。

扩展会读取当前活动输入法状态，用于判断微软拼音或搜狗拼音当前是中文还是英文，并在需要时请求切换对应输入法的内部中英文状态。

## 本地写入

扩展不会修改源文件内容，不自动替换标点，不写入候选词，不记录键盘输入。

扩展会写入 Visual Studio 用户设置中的长期配置，包括：

- 是否启用自动切换。
- 是否显示左下角状态栏。
- 手动覆盖光标颜色。
- 是否自定义状态栏文字颜色。
- 状态栏文字颜色。

临时暂停状态只保存在当前 VS 进程内，不写入 Visual Studio 用户设置。

## 不做的事

- 不联网。
- 不采集遥测。
- 不读取或上传完整键盘记录。
- 不读取或上传输入法候选词。
- 不主动安装、添加或切换系统键盘布局。
- 不修改系统默认输入法、微软拼音快捷键或兼容模式。
- 不写入 Visual Studio 的字体和颜色主题配置。

## 诊断与反馈

构建和验证脚本默认在运行者本机执行，不包含数据上传逻辑。反馈问题时，建议使用 `samples` 目录中的无敏感示例复现，并记录系统版本、VS 版本、扩展版本、输入法版本、操作步骤和实际表现。不需要提交私人源码、候选词或完整按键记录。
