## 已知限制

- 当前安装包仅声明 x64，不承诺 ARM64。
- 微软拼音旧版兼容模式不属于当前支持范围。
- 后台词法分析器不是完整编译器；C++ 预处理器复杂分支/拼接、C# 插值格式段和不完整语法可能存在识别偏差。
- 编译、模拟宿主、COM 检查和离屏绘制测试不能替代所有 Visual Studio 版本及显示缩放组合的实机验证。
- Windows 的输入态可能受“每个应用窗口使用不同输入法”等系统选项影响；扩展不能保证离开 VS 后系统完全不会继承原输入态。

后续版本继续按 `MANUAL-TESTS.md` 执行回归验证。扩展不会修改默认输入法、微软拼音兼容设置、VS 工作负载或日常 VS 配置。
